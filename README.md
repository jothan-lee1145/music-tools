# 📘 Music Toolbox Wiki

## 📖 概述
**Music Toolbox** 是一款基于 Python 与 Tkinter 开发的桌面音乐工具集。采用模块化架构设计，集成元数据标签写入、多源音乐下载、音频格式转换与歌词嵌入四大核心功能。项目注重线程安全、网络容错与跨平台兼容性，适合音乐爱好者、本地曲库管理者及音频处理初学者使用。

## 🛠️ 安装与依赖

### 环境要求
- Python 3.8+
- FFmpeg（静态编译版或已加入系统 `PATH`）
- Windows / macOS / Linux（跨平台兼容）

### 依赖安装
```bash
pip install requests mutagen Pillow
```

### FFmpeg 配置
1. 下载对应系统的静态编译版：[FFmpeg 官方下载页](https://ffmpeg.org/download.html)
2. 解压后将 `ffmpeg` 可执行文件所在目录添加至系统环境变量 `PATH`
3. 验证安装：终端执行 `ffmpeg -version` 应正常输出版本信息

## 📘 模块使用指南

### 1. 标签嵌入 (Tab 1)
1. 输入歌曲名或艺术家，点击 **搜索**
2. 在左侧表格选择目标曲目，右侧面板自动加载高清封面与元数据预览
3. 点击 **选择文件** 加载本地音频（支持 MP3 / FLAC / M4A / WAV）
4. 点击 **写入标签/封面** 完成元数据注入

> [!NOTE]
> 试听功能仅对 iTunes 数据源有效（依赖官方返回的 30 秒预览链接）

### 2. 音乐下载 (Tab 2)
1. 选择稳定来源（默认网易云）与目标音质
2. 搜索后在表格选中曲目，点击 **下载选中**
3. 设置保存路径后自动开始流式下载，底部状态栏显示实时进度百分比
4. 下载完成后弹窗询问是否自动写入标签与封面

> [!WARNING]
> 免费聚合 API 存在频率限制，程序已内置 `0.2s` 请求间隔机制防止封禁

### 3. 格式转换 (Tab 3)
1. 设置输出目录，选择质量预设（原声保留 / 48kHz+512K 定制压缩）
2. 点击 **添加文件** 批量导入待转换音频
3. 点击 **开始转换**，后台线程池自动分配任务（默认 2 并发）
4. 转换完成后弹窗提示，支持一键打开输出文件夹

> 转换队列采用 `queue.Queue` 管理，UI 主线程与 FFmpeg 子进程完全隔离，界面零卡顿。

### 4. 歌词嵌入 (Tab 4)
1. 选择目标音频文件
2. 切换歌词来源模式：
   - **本地文件**：选择 `.lrc` 或 `.txt`，程序自动探测 UTF-8 / GBK 编码
   - **API 获取**：输入歌名/歌手，点击自动获取（内置网易云 → 酷我自动降级重试）
3. 可在文本框手动校对或编辑歌词内容
4. 点击 **嵌入歌词** 写入音频容器

> [!IMPORTANT]
> MP3 歌词写入已绕过 `mutagen.mp3.MP3.save()` 的 MPEG 帧同步检查，直接操作 ID3v2 容器，大幅降低损坏文件报错率。

## ⚙️ 技术架构

### 模块化设计
- 主界面 `main.py` 仅负责 UI 组装、路由分发与状态变量传递
- 各功能模块独立封装于 `modules/` 目录，通过回调函数共享能力（如下载完成后注入标签模块）
- 彻底避免循环导入，支持按需横向扩展新模块

### 线程安全模型
- 所有网络请求、文件 IO 与耗时操作均在 `daemon=True` 后台线程执行
- UI 状态更新严格通过 `root.after(0, callback)` 派发至 Tkinter 主线程
- 状态栏变量按模块物理隔离 (`status1` ~ `status4`)，防止竞态条件

### 多线程转换机制
```python
# converter.py 核心调度逻辑
self.task_queue = queue.Queue()
for _ in range(self.MAX_WORKERS):  # 默认并发数 2
    threading.Thread(target=self._worker, daemon=True).start()

def _worker(self):
    while True:
        try:
            inp = self.task_queue.get(timeout=1)
        except queue.Empty:
            break
        self._process_file(inp)
        self.task_queue.task_done()
```
- 严格限制 FFmpeg 并发数，防止 CPU/内存瞬时过载
- 任务完成自动回收工作线程，支持队列重复触发

### 网络与会话管理
- 全局单例 `requests.Session` 复用 TCP 连接池与 Cookie
- 自动注入浏览器级 `User-Agent`、`Referer` 与 `Accept-Language` 降低 API 拦截概率
- 代理环境变量热读取，无需修改源码即可切换网络通道

## 🐛 常见问题排查

| 现象 | 原因分析 | 解决方案 |
| :--- | :--- | :--- |
| `ModuleNotFoundError` | 虚拟环境未激活或依赖未安装 | 执行 `pip install requests mutagen Pillow` 并重启 IDE |
| `未检测到 FFmpeg！` | FFmpeg 未加入系统 `PATH` | 下载静态版配置环境变量，终端运行 `ffmpeg -version` 验证 |
| `cannot sync to MPEG frame` | MP3 文件帧头损坏或标签偏移异常 | 程序已内置直写 ID3 修复逻辑；若仍报错，使用 `ffmpeg -i in.mp3 -c copy fixed.mp3` 重封装源文件 |
| 歌词显示乱码 | 原始文件编码非 UTF-8 | 程序内置 UTF-8/GBK 自动回退探测；仍乱码请手动转码为 UTF-8 无 BOM 格式 |
| API 搜索无结果 | 关键词匹配度低或目标源暂不可用 | 简化搜索词（仅保留歌名），或切换 iTunes 区域源重试 |
| 转换队列卡住 | FFmpeg 子进程异常退出或源文件损坏 | 检查源文件完整性；查看终端错误堆栈；将并发数临时降至 1 排查 |
